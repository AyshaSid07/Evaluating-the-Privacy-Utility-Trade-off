# Results 

This folder contains the experimental results generated during the evaluation process.

------------------------------------------------------------

## `utility`

Contains utility evaluation results for the ACS Public Coverage.

### `acs_public_coverage_utility_results.csv`

Stores:
- accuracy
- precision
- recall
- F1-score

for the evaluated datasets.

-------------------------------------------------------

## `aia`

Contains Attribute Inference Attack (AIA) evaluation results.

### `public_coverage_aia_results.csv`

Stores the Attribute Inference Attack evaluation results.

-------------------------------------------------------

## `dcr`

Contains Distance to Closest Record (DCR) evaluation results.

### `dcr_results_acs_public_coverage.csv`

Stores the Distance to Closest Record evaluation results.

------------------------------------------------------

## `linkage`

Contains linkage attack evaluation results.

### `linkage_attack_results_acs_public_coverage.csv`

Stores the linkage attack evaluation results.
