# Anonymization 

This folder contains the anonymization implementation used in the Credit Card Clients dataset.

The anonymization process generates privacy-preserving datasets using:
- k-anonymity
- l-diversity
- t-closeness
- differential privacy

------------------------------------------------------------------------------------------

## `add_index.py`

Adds a unique `Linkage_Index` column to the original dataset.

The index is used to:
- uniquely identify records
- compare original and protected records during evaluation
- compute re-identification success rates

### Run

```bash
python add_index.py
```

---------------------------------------------------------------------------------------

## `ARX_credit_card_clients.java`

Main anonymization program implemented using the ARX framework.

The program:
- loads the Credit Card Clients dataset
- defines quasi-identifiers
- loads hierarchy files for attribute generalization
- applies k-anonymity
- applies l-diversity
- applies t-closeness
- exports anonymized datasets as CSV files

### Sensitive Attribute
- `LIMIT_CATEGORY`

### Quasi-Identifiers
- SEX
- EDUCATION
- MARRIAGE
- AGE

### Requirements
- Place hierarchy CSV files inside the `hierarchies/` folder
- Place `credit_card_clients_binned.csv` inside the `datasets/` folder
- Add the ARX library JAR file to the Java project classpath before running the program

### Compile

```bash
javac ARX_credit_card_clients.java
```

### Run

```bash
java ARX_credit_card_clients
```

----------------------------------------------------------------------------

## `clean_arx_data.py`

Cleans anonymized datasets generated by ARX.

The script:
- reads anonymized datasets
- detects fully suppressed rows where all quasi-identifiers contain `*`
- removes fully suppressed rows
- saves cleaned datasets

### Run

```bash
python clean_arx_data.py
```

----------------------------------------------------------------------------------

## `credit_card_clients_dp.py`

Implements differential privacy synthetic data generation using SmartNoise.

The script:
- loads anonymized Credit Card Clients datasets
- preprocesses categorical and continuous attributes
- generates synthetic datasets using the MST synthesizer
- applies different epsilon values
- exports differentially private datasets

### Run

```bash
python credit_card_clients_dp.py
```
